# PC10 QA Notes — Global Subsidence Showcase

## Scope & Integrity
- **Data class:** Strictly `provisional` (CRID `P05023`, all acquisition dates `>= 2026-06-17`). No `beta-precal` products were used.
- **Unmodified upstream code:** `pipeline/subset.py` (PC2) and `analysis/cumulative.py` (PC3) were imported and executed unchanged via in-memory site registration in `pipeline/pc10/run_city.py`.
- **Raw data hygiene:** Every `.h5` file was downloaded one at a time into `raw/pc10/` and deleted immediately after subsetting.

## Findings & Caveats
1. **Reference-window sensitivity in Mexico City & Tehran:**
   - Automatic reference selection (`choose_reference` by highest mean coherence) placed the primary reference near the northeastern lakebed margin in Mexico City (`-99.0126E, 19.5872N`) and in the southwestern plain in Tehran (`51.1999E, 35.5448N`), both of which can experience background motion. Re-referencing `>= 30 km` away to bedrock/foothill margins increased the measured peak from `-4.4` to `-7.4 cm` LOS in Mexico City and from `-3.5` to `-7.3 cm` LOS in Tehran. Both values are preserved transparently in `summary.json` (`range_cm`).
2. **Jakarta low valid fraction (`valid_frac_full_chain = 0.029`):**
   - Path 18, Frame 91 only clips the northeastern corner of the Jakarta bounding box, and two September pairs (`2026-09-07_2026-09-19` and `2026-09-19_2026-10-01`) had `94.2%` and `95.0%` NaN after `connectedComponents` / coherence masking. Consequently, only `2.9%` of the grid was valid across all 8 pairs, and only 1 reference window was available (`range_cm = null`). Reported as-is per `tasks/PC10.md`.
3. **DEM unavailable (`No module named 'rasterio'`):**
   - `analysis/cumulative.py` fell back to plane-only per-pair deramping (no elevation-correlated tropospheric term). Noted in `meta.json`.

5. **4th global city (Beijing, `data/global/beijing/`):**
   - Path 47, Frame 68, Descending: 9 consecutive provisional P05023 pairs (`2026-06-17` to `2026-10-15`, 120 days), `valid_frac_full_chain = 0.711`, `ref_mean_coh = 0.92`.
   - Primary reference in Tongzhou (`116.7083E, 39.9337N`) yields `-1.4 cm` LOS (`-4.3 cm/yr` est.), while re-referencing to the NW foothill window (`116.3106E, 40.1007N`) yields `-7.6 cm` LOS (`range_cm = [-7.6, -1.4]`).
6. **Mexico City off-basin re-run (`pipeline/pc10/rerun_mexico_city.py`):**
   - Previous automatic reference (`-99.0126E, 19.5872N`, inside the northern Texcoco/Ecatepec lakebed) yielded `-4.4 cm` LOS because the reference itself was subsiding (~`+2.26 cm` median offset relative to the SW volcanic bedrock margin).
   - Re-referencing to the stable SW volcanic margin (`-99.1840E, 19.3767N`, `mean_coh = 0.82`) changed peak subsidence from **`-4.4 cm` to `-7.0 cm` LOS** (difference: **`2.6 cm`**), `p2_cm = -5.7 cm`, `rate_cm_per_100d = -5.8 cm/100d`, `max_subsidence_vertical_cm_estimate = -9.7 cm`, `rate_cm_per_yr_estimate = -21.2 cm/yr` LOS (`valid_fraction = 0.639`).
7. **Bangkok (`data/global/bangkok/`):**
   - Path 112, Frame 8, Ascending: 8 pairs (`2026-06-21` to `2026-10-19`, 120 days), `valid_fraction = 0.303`, `ref_mean_coh = 0.91`, `max_subsidence_cm = -7.5 cm` LOS (`rate_cm_per_100d = -6.2`, `p2_cm = -6.9`, `range_cm = [-7.9, -7.5]`).
   - Visual check of `disp/2026-10-19.png` shows the main Bangkok urban core subsiding ~`-2` to `-3.5 cm` LOS, while an isolated eastern strip (`100.7374E, 13.8137N`) across a sharp linear boundary reads `-7.5 cm` (possible unwrapping-component offset across low-coherence paddy/canal boundary; flagged for PC5 review).
