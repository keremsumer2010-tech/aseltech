# SÖZLÜK

| Terim | Anlamı |
|---|---|
| NISAR | NASA-ISRO SAR uydusu (2025'te fırlatıldı); L-band (ve S-band) radar |
| SAR | Synthetic Aperture Radar — kendi sinyalini gönderen, bulut/gece fark etmeyen görüntüleme radarı |
| L-band | ~24 cm dalga boyu; bitki örtüsünün içine girer, yer hareketi ölçümü için iyi |
| GUNW | Geocoded Unwrapped Interferogram — iki tarih arası faz farkı, haritaya oturtulmuş, 80 m |
| GCOV | Geocoded Covariance — araziye göre düzeltilmiş radar parlaklığı (gamma0), HH/HV |
| SME2 | NISAR L3 toprak nemi ürünü |
| Browse PNG | Ürünün hızlı önizleme görüntüsü; nicel değil (`preview`) |
| Faz (phase) | Radar dalgasının döngüdeki konumu; iki tarih arası faz farkı mesafe değişimini verir |
| Unwrapped phase | 2π döngüleri açılmış, sürekli faz — cm'ye çevrilebilir |
| İnterferogram | İki tarihin faz farkı görüntüsü |
| LOS (line of sight) | Uydu–yer bakış doğrultusu; radar bu doğrultudaki hareketi ölçer (tam dikey değil) |
| Incidence angle | Radar ışınının yere geliş açısı; LOS→dikey dönüşümde kullanılır |
| Coherence | 0–1 arası güvenilirlik; düşükse (su, yoğun bitki, değişen yüzey) faz güvenilmez → maskelenir |
| Referans noktası | Hareketsiz kabul edilen bölge; tüm değerler buna göre sıfırlanır |
| Kümülatif çökme | Ardışık interferogramların toplamı — başlangıçtan beri toplam hareket |
| Akifer sıkışması | Yeraltı suyu çekilince kil katmanların sıkışması; kalıcı (inelastik) kısmı geri gelmez |
| Elastik / inelastik | Geri dönen (mevsimsel) / kalıcı çökme |
| Obruk | Karstik zeminde aniden açılan çukur (sinkhole); Karapınar'da yeraltı suyu düşüşüyle ilişkili |
| GNSS / GPS istasyonu | Yerdeki sabit uydu konum alıcısı; dikey hareketi bağımsız ölçer → doğrulama |
| PROVISIONAL | NISAR'ın geçici (kesinleşmemiş) ürün sürümü |
| ATBD | Algorithm Theoretical Basis Document — resmi algoritma açıklaması ve notebook'ları |
| MintPy | Açık kaynak InSAR zaman serisi aracı (ATBD notebook'larının temeli) |
| OSM | OpenStreetMap — açık harita verisi (ODbL lisansı) |
| bbox | Bölge sınırı: lon_min, lat_min, lon_max, lat_max |
| EPSG | Koordinat sistemi kodu (ör. UTM bölgesi) |
