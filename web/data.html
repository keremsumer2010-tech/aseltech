Reproduce our data in 5 steps

  1. Get a free NASA Earthdata login at urs.earthdata.nasa.gov and put it in your ~/.netrc file (instructions in the README).
  2. Find the radar pairs. In ASF Vertex (or with Python) search for NISAR GUNW products over your area, with both dates on or after 17 June 2026 and release P05023 (provisional). Our list: python pipeline/search.py central_valley. 
    import asf_search as asf
asf.search(platform="NISAR", processingLevel="GUNW",
           intersectsWith="POLYGON((-120.2 35.6,-119 35.6,-119 36.6,-120.2 36.6,-120.2 35.6))",
           start="2026-06-17", end="2026-10-31")
  3. Download and cut each pair to the study box (about 2.4 GB in, 20 MB out): python analysis/fetch_subset.py central_valley 34 020 100 (track 34, frame 20).
  4. Turn phase into centimetres and add the pairs up: python analysis/cumulative.py central_valley. This writes the maps, points and summary listed above.
  5. Check your result against ours (summary.json) and against GPS: python validation/compare.py. All tests: python -m pytest analysis -q.

Needs Python 3.11+ and pip install asf_search h5py numpy scipy matplotlib pyproj rasterio shapely requests pytest. Without an Earthdata login you can still open every file on this page.

Source data

NISAR data are provisional. Calibration and validation are carried out by the NISAR project (NASA-JPL and ISRO), not by our team.
