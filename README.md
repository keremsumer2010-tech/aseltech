# Sinking Farmlands — NISAR Space Apps 2026

Team Taykut · NASA Space Apps Challenge 2026 · Challenge: **Dancing with the SARs**

NISAR radar measures how farmland sinks and rebounds as groundwater is pumped.
We turn interferograms into centimetres, human-scale stories and risk maps.

Study areas: California Central Valley (USA) · Konya Plain (Türkiye) · Fens (UK, crops/soil moisture).

Data: NASA-ISRO NISAR (GUNW, GCOV, SME2) via ASF DAAC. Data are PROVISIONAL.
